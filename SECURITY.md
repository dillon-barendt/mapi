# Security

Mapi is a public portfolio project with synthetic examples only.

Do not commit:

- Real broker, customer, marketplace, provider, or inventory data.
- Venue exports that identify private customer workflows.
- Credentials, cookies, tokens, API keys, or provider data.
- Local `.env` files, IDE metadata, cache directories, or generated artifacts.

If you find a security issue, report it through GitHub issues when appropriate.
For sensitive reports, use a private contact channel when one is available.
